# Security policy

tokensaver runs offline and never sends prompts anywhere. If you find a way it could leak
a prompt, run untrusted code, or be tricked into overwriting a file it should not, please
report it privately.

## How to report

Use **[Report a vulnerability](https://github.com/behrouzbk/tokensaver/security/advisories/new)**
on GitHub (private), or email **info@axieo.ca**. Please do not open a public issue.

You will get a reply within five business days. Fixes are released as soon as possible,
and reporters are credited unless they prefer not to be.

## Supported versions

Only the latest release receives security fixes.
